# Карта пам'яті: генератор тепла, Delta TP70P (ядро ПЛК DVP-SS2), ISPSoft

Логіка входів: усі захисні входи **нормально замкнені (fail-safe)**: ON = норма.
Обрив дроту читається як аварія.

## Фізичні входи (X)
| Адреса | Сигнал | ON означає |
|---|---|---|
| X0 | Аварійна зупинка (NC) | E-Stop НЕ натиснута |
| X1 | Сканер полум'я | Полум'я є |
| X2 | Реле тиску повітря | Тиск повітря від вентилятора є |
| X3 | Реле мін. тиску газу/палива (NC) | Тиск у нормі |

## Фізичні виходи (Y)
| Адреса | Навантаження |
|---|---|
| Y0 | Вентилятор продувки камери згоряння |
| Y1 | Трансформатор розпалу |
| Y2 | Запірний клапан палива |
| Y3 | Аварійна сирена |

## Команди з HMI (TP-Editor, кнопки без фіксації)
| Адреса | Функція |
|---|---|
| M100 | ПУСК системи |
| M101 | СТОП системи |
| M102 | СКИДАННЯ аварії |
| M103 | ВИМКНУТИ сирену |

## Стани кроків (лише один активний)
| Адреса | Крок | Колір на HMI | D150 |
|---|---|---|---|
| M10 | Очікування / готовність | сірий / зелений, якщо M0 | 0 |
| M11 | Попередня продувка | жовтий | 1 |
| M12 | Передрозпал (лише іскра) | жовтий | 2 |
| M13 | Час безпеки (іскра + клапан) | жовтий | 3 |
| M14 | Робота пальника | зелений | 4 |
| M15 | Постпродувка | жовтий | 5 |
| (M50) | Блокування через аварію | червоний | 9 |

## Службові біти
| Адреса | Призначення |
|---|---|
| M0 | Ланцюг безпеки в нормі (X0 · X3 · немає аварії) |
| M20 | Є запит на тепло (гістерезис) |
| M21 | Систему увімкнено оператором |
| M30 | Тиск повітря підтверджено під час продувки |
| M50 | Загальна аварія (OR M51..M59), блокування |
| M60 | Уставки некоректні, пуск заборонено |
| M104 | Сирену вимкнено (квитовано) |

## Аварії (з фіксацією, перша причина видна на HMI)
| Адреса | Аварія |
|---|---|
| M51 | Натиснута аварійна зупинка |
| M52 | Низький тиск газу/палива під час роботи |
| M53 | Немає / втрачено тиск повітря (вентилятор) |
| M54 | Паразитне полум'я до розпалу |
| M55 | Невдалий розпал (немає полум'я за час безпеки) |
| M56 | Згасання полум'я під час роботи |
| M57 | Перегрів (D102 >= D106) |
| M58 | Залипло реле тиску повітря (X2=ON при вимкненому вентиляторі) |
| M59 | Несправність датчика температури (D102 поза 0..999) |

## Регістри даних (D), ціле значення в °C
| Адреса | Призначення | Типово |
|---|---|---|
| D100 | Уставка температури | 60 |
| D102 | Поточна температура (з аналогового входу) | — |
| D104 | Гістерезис | 3 |
| D106 | Межа перегріву | 90 |
| D110 | Розрахунок: D100 + D104 (вимкнення пальника) | — |

| D150 | Код стану для HMI | — |

## Таймери (T0..T199 = 100 мс)
| Таймер | Уставка | Призначення |
|---|---|---|
| T0 | K300 = 30 с | Попередня продувка |
| T1 | K20 = 2 с | Передрозпал |
| T2 | K30 = 3 с | Час безпеки (TSA) |
| T3 | K300 = 30 с | Постпродувка |
| T4 | K100 = 10 с | Тайм-аут підтвердження тиску повітря |
| T5 | K10 = 1 с | Стабілізація полум'я |
| T6 | K50 = 5 с | Фільтр залипання реле повітря |
| T7 | K20 = 2 с | Фільтр паразитного полум'я |
| T8 | K10 = 1 с | Фільтр несправності датчика |

Часи T0, T2, T3 потрібно звірити з паспортом пальника та нормами (наприклад, EN 676 / EN 298).
